# Blueprints

> **Path:** Items / Blueprints

Blueprints are recipes you can own and store. If you have the blueprint, you can craft the item on the **Craft** page.

## Blueprint Storage

In-game, the **Blueprints** page is now intentionally *just* your storage grid (your owned blueprints).

- Storage is slot-based (currently shown as **16 slots** in the UI).
- Crafting pulls from what you own in storage.

## Blueprint Library

The old **Blueprint Library** (the big “all blueprints in the game” list with sorting) was removed from the in-game Blueprints page to keep the page clean and make it faster to scan.

This wiki page is the new home for that information.

What the Blueprint Library is meant to contain:

- A list of **every blueprint** in the game (owned + unowned).
- Sorting by **Type**, **Tier**, and **Name**.
- A quick way to check “does this blueprint exist?” even if you don’t own it yet.
